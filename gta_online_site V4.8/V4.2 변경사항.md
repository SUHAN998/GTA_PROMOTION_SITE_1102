# V4.2 — 03번 고정 위치 및 화면 높이 수정

영상에서 03번 콘텐츠가 화면 아래로 잘린 상태로 진행되는 현상을 확인했습니다.

- 고정 시작 지점을 화면 높이 15%에서 최상단으로 변경했습니다.
- 고정 섹션의 전체 높이를 실제 브라우저 뷰포트 높이로 맞췄습니다.
- 내비게이션 높이와 위아래 24px 여백을 제외한 영역에 콘텐츠를 배치합니다.
- 세로로 긴 이미지가 섹션 높이를 늘리지 않도록 가용 높이 안에서 전체 이미지가 보이게 맞췄습니다.
- 높이 800px 이하에서는 03번의 숫자·제목·본문과 간격을 줄였습니다.
- 폭 900px 미만 또는 높이 600px 미만에서는 잘림을 피하기 위해 고정을 해제합니다. 이 경우에도 등장·역재생은 ScrollMagic 진행률에 연동됩니다.
- 창 크기를 바꾸면 높이, 내비게이션 여백 및 고정 여부를 갱신합니다.

03번의 이미지 → 숫자 → 제목 → 본문 순서, 스크롤 정지 시 상태 유지, 위로 스크롤 시 역재생은 유지했습니다.

검증: JavaScript 문법 및 모의 실행을 통한 데스크톱/모바일/낮은 창 전환, 고정 위치, 헤더 높이, 역재생 설정을 점검했습니다. 사용자 영상은 프레임을 추출하여 확인했습니다. 수정 후 실제 브라우저 렌더링은 아직 검증하지 못했습니다.
