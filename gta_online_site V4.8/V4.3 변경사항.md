# V4.3 — 본문 배경 및 차량 포디움 첫 등장

## 변경 파일

- `index.html`: 새 CSS/JS 연결 및 실제 차량 PNG 5개에 내부 래퍼 추가.
- `section-polish.css` (추가): 본문 배경 2곳, 차량 래퍼의 등장 상태 및 동작 줄이기 대응.
- `podium-reveal.js` (추가): IntersectionObserver를 이용한 최초 진입 감지, 재실행 방지, 오류 시 표시 처리.

기존 `style.css`, `design-system.css`, `interaction-system.css`, `script.js`, `interactions.js`는 V4.2와 동일합니다. 히어로 마크업, 섹션 순서, 카드 및 캐러셀의 이동 코드를 유지했습니다.

## 배경

- 혜택: 기존 `Los Santos Sunset.png` 도시 이미지 위에 86% 검정 오버레이를 적용했습니다. 위아래는 검정으로 연결합니다.
- 주간 업데이트: 기존 `Racing1.png` 차량 이미지 위에 88% 검정 오버레이를 적용했습니다. 위는 검정, 아래는 인접 경력 섹션의 #0b0b0b로 연결합니다.
- 지도·차량 포디움의 단색 배경과 다른 섹션의 기존 이미지 연출은 유지합니다.
- 배경은 CSS 배경 레이어이므로 텍스트나 카드를 덮거나 배치를 변경하지 않습니다. 이미지 요청 실패 시 기존 단색 배경이 남습니다.

## 차량 등장

- 포디움 최초 진입 시 내부 래퍼가 아래 36px에서 원위치로 700ms 동안 페이드인합니다.
- 완료 후 관찰을 해제하고 표시 상태를 유지하므로 다시 스크롤해도 재실행하지 않습니다.
- 슬라이드의 기존 패딩 안에 폭·높이 100% 래퍼를 두어 PNG의 크기 제한과 중앙 정렬을 유지합니다.
- 슬라이드 트랙과 다른 요소에서 transform을 사용하므로 캐러셀 이동과 분리됩니다.
- 동작 줄이기, IntersectionObserver 미지원, 초기화 예외, 이미지 오류는 즉시 표시 처리합니다. JavaScript가 전혀 실행되지 않아도 기본 CSS는 표시 상태입니다. 이미지 오류 처리 자체가 유실된 PNG를 복구하지는 않습니다.
- 관찰 이벤트가 전달되지 않는 경우를 위한 가벼운 스크롤/리사이즈 확인도 최초 등장 후 해제합니다.

## 검증 결과와 남은 확인

통과: 새 JS 문법 검사, 기존 히어로 마크업 및 스타일/캐러셀 코드 동일성 검사, 모의 DOM에서 최초 진입·재진입·동작 줄이기·이미지 오류·초기화 실패·관찰 미지원/대체 감지 검사. 기존 캐러셀 코드를 데스크톱/모바일 폭으로 모의 실행하여 이전/다음/양 끝 순환/리사이즈 동작도 점검했습니다.
